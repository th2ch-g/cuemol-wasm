# Third-party source and licenses

The browser adapter in this repository is licensed under the MIT license. Bundled components retain their own licenses.

The published [source manifest](https://th2ch-g.github.io/cuemol-wasm/source.json) records the exact CueMol and adapter source archives, compiler revision, dependency URLs, and SHA-256 checksums for each deployment. The build recipes and browser patch are included in the adapter source archive. [Build metadata](https://th2ch-g.github.io/cuemol-wasm/version.json) identifies the native binary by SHA-256.

The deployed application includes license texts under [licenses/](https://th2ch-g.github.io/cuemol-wasm/licenses/CueMol.txt). The complete source for native dependencies is available at the URLs and checksums in source.json. Source for npm packages is identified by package-lock.json and its package registry tarball URLs.

The CueMol test fixtures come from its tests/test_data directory. Synthetic density and trajectory fixtures are generated by scripts/generate-fixtures.py and are used only for software verification.
